# NLP Review Analysis
A simple Python script that performs sentiment analysis on Amazon Fine Food Reviews.

## Files:
- `review_analysis.py`: The main analysis script.
- `Reviews.csv`: The dataset of Amazon Fine Food reviews.

## How to Run:
1. Download the dataset from Kaggle.
2. Run the script using Python 3.
